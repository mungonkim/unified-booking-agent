# 통합 예약 에이전트

📄 [소개 페이지 보기](https://claude.ai/artifact/G6vfENcMVS7S5K4oiKfGYC) — 진행 상황을 상태판 형태로 정리해뒀습니다.

네이버 예약, 캐치테이블 등 여러 예약 플랫폼에 흩어진 식당·병원·미용실·사진관 등 다양한 업종의 예약 정보를, 사용자가 자연어로 물어보면 통합해서 확인해주는 개인용 에이전트입니다.

- 가장 빠르게 예약 가능한 날짜/시간을 찾아주거나, 특정 날짜의 가능 시간을 조회
- 결제가 필요 없는 예약이면 에이전트가 예약까지 자동으로 진행
- 결제가 필요한 예약이면 자동으로 진행하지 않고, 사용자가 직접 결제할 수 있도록 안내
- 원하는 조건(업종, 지역, 시간대 등)에 맞는 장소 추천

> 이 저장소에는 예약 페이지의 실제 셀렉터/마크업 대응 로직(`booking_engine.py`)은 포함되어 있지 않습니다. 개인적으로 만든 자동화 노하우라 로컬에만 두고, 어떤 걸 만들고 있는지 구조와 진행 상황만 공개합니다.

## 진행 상황 체크리스트

### 네이버 예약
- [x] 자연어 질의 → 장소/담당자/인원/조회모드 파싱 (Claude API)
- [x] 검색결과 다건 시 자동/대화형 선택
- [x] 업종별 중간 선택 화면 대응 (디자이너 위젯 / 서비스카드 / 룸·상품 목록)
- [x] 신형·구형 캘린더 마크업 모두 대응
- [x] 가장 빠른 예약 가능 날짜 탐색
- [x] 특정 날짜의 예약 가능 시간 조회
- [x] 같은 장소·같은 항목 후속 질문 시 세션 재사용 (재검색 생략)
- [ ] 결제 없는 예약 자동 완료(실제 예약 신청까지)
- [ ] 결제 필요 여부 자동 판단
- [ ] 결제 필요 시 사용자에게 결제 링크 전달 후 대기

### 캐치테이블
- [ ] 검색 → 예약 페이지 진입
- [ ] 가용 시간 조회
- [ ] 결제 없는 예약 자동 완료 / 결제 필요 시 사용자 안내

### 플랫폼 공통
- [ ] 네이버/캐치테이블 등을 공통 인터페이스로 묶는 어댑터 계층
- [ ] 조건 기반 장소 추천 (업종/지역/시간대 등)
- [ ] 여러 플랫폼 결과를 합쳐서 하나의 답변으로 제공

### 그 외
- [ ] 멀티 유저 동시 서비스화 (현재는 개인용 단일 세션 — 의도적으로 보류 중)

## 실행 (현재 구현 범위: 네이버 예약 조회)

```bash
.\.venv\Scripts\python.exe main.py           # 자연어 질의 모드
.\.venv\Scripts\python.exe main.py --menu    # 레거시 CLI 메뉴 모드
```

`.env`에 `ANTHROPIC_API_KEY`가 필요하며, 실행 전 `booking_engine.py`(예약 로직)가 프로젝트 루트에 로컬로 존재해야 합니다.
